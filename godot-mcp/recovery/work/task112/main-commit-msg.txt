feat(godot-mcp): TASK-112 - the evidence-tier ladder for the coverage ledger, the three engine defect fixes it drove, and the third batch's account

Engine side (separate repo, pushed as ba1587c71e): the three defects TASK-111
registered are fixed at the root. D-T111-1 was blocking and silent - the atomic
publish registered a resource's UID under the `<name>.mcp-tmp.<ext>` scratch
name, so a scene saved afterwards resolved the ext_resource BY UID to a file
that does not exist, with exit code 0. D-T111-2 made
`editor_add_resource_to_node_property` refuse the very component-object spelling
its own error message asked for. D-T111-3 validated nothing on
`editor_add_raycast.dimension`, so `"4d"` silently built a `RayCast3D`; it is now
a closed set and the contract declares the enum (generator 1.22.0 -> 1.23.0).

Ledger side (this repo): `tools/tool_coverage.py` now labels every contract tool
with an evidence TIER instead of leaving "effective >= 1" as a pass/fail bit:

    pixel_effect > file_effect > readback > count_only        (0 calls -> no_calls)

`readback` has two explicitly different kinds. `witness_read` is a WRITE tool's
effect corroborated by an INDEPENDENT READ CALL in the same run; the pairing is
NOT inferred - it is declared in the session manifest's `readback` array
(`tools/sessions/_exercises/**/*-manifest.json`) and the ledger re-finds the
witness in that run's trace (must exist, must be ok=true, must carry a
substantive payload) before granting the tier. `own_payload` is a READ-verb
tool, whose answer IS the measurement (the TASK-111 READ_VERBS rule). A write
tool's own "success" text is never a readback witness.

This batch declared 22 witness pairs, verified 20, and REJECTED 2
(`editor_add_gridmap <- editor_get_scene_tree` and `editor_connect_signal <-
editor_list_signal_connections` have no qualifying witness in the named runs).
The rejections are printed in TOOL-COVERAGE.md section 0.1 rather than hidden.
Tier distribution: pixel_effect 27 / file_effect 24 / readback 77 (57
own_payload + 20 witness_read) / count_only 9 / no_calls 40 = 177.

The 29 writers that were "counter met, evidence missing" now each carry a tier;
9 remain `count_only` and the report says why one by one. TOOL-COVERAGE.md also
gains section 0.2 (per-tier tool lists) and a 档位 column in every table.
