B) "Can a C# game export to Web?" - answered by measurement, not opinion:
   IMPOSSIBLE on Godot 4. The gate is compile time and lives at
   platform/web/export/export_plugin.cpp:424-429 (#ifdef MODULE_MONO_ENABLED ->
   return false) and fires BEFORE the template check. Three experiments:
     (1) mono editor + real C# game  -> refuse
     (2) mono editor + a PURE GDScript project -> the SAME refusal verbatim
         (this is what rules out "the project's C# did it")
     (3) non-mono editor + that same GDScript project -> passes the .NET gate and
         only reports the missing web_nothreads_*.zip template
   The web template could not be built here: scons rejects the platform outright
   while emcc is absent (platform/web/detect.py:29-30), and after staging
   emcc 6.0.10 by hand the build still dies in platform/web/*.cpp with 12-13
   libc++ header-search-order errors.
